# 오늘 순매수 — 코스피·코스닥 투자자별 자금 흐름

Claude에게 **"오늘 순매수"**라고 말하면, 그날 코스피·코스닥에서 외국인·기관·개인의 돈이
**어느 섹터, 어느 종목으로 얼마나 들어오고 빠졌는지** 계산해 한 장짜리 HTML 페이지로 보여주는 Claude 스킬입니다.

단순한 순위 나열이 아니라 "오늘 돈이 어디로 갔나"를 한눈에 보는 것이 목적입니다.

## 페이지에 나오는 것

시장(코스피/코스닥) 탭마다 위에서부터:

1. **시장 전체 수급** (정확값): 외국인·기관·개인 오늘·5일 순매수, 기관 세부(금융투자·투신·보험·연기금 등).
   기관 매수가 금융투자 위주(ETF·차익거래 성격일 수 있음)면 경고. 외국인 코스피200 선물 계약, 원·달러 환율.
   옵션 만기·동시만기·MSCI 리밸런싱 날이면 경고.
2. **내 관심 종목**: 등록한 종목의 오늘·5일·20일 수급, 연속 일수, 20일 주가.
3. **오늘 눈여겨볼 변화** (외국인+기관 기준)
   - 수급 전환: 앞 15일은 빠지다가 최근 5일 들어오기 시작한 종목
   - 연속 순매수: 5일 이상 연속으로 산 종목
   - 신규 쌍끌이: 오늘 외국인·기관이 같이 샀고 어제는 아니었던 종목
   - 수급 강도: 덩치 대비 많이 산 종목 (순매수 ÷ 시가총액)
4. **주가와 수급이 엇갈린 종목**: 주가는 빠졌는데 외+기가 산 종목 / 주가는 올랐는데 외+기가 판 종목
5. **오늘 자금 흐름**: 들어온/빠진 섹터(주도 종목·한 종목 쏠림 표시)와 종목 TOP 15, 보기 전환(외+기/외국인/기관/개인)
6. **섹터 추세**: 최근 20거래일 누적 유입/유출 섹터, 일별 막대, 연속 일수
7. **신호 점검**: 지난 20일 동안 '수급 강도 상위 20종목'을 매일 골랐다면 5일 뒤 시장보다 나았는지
8. 투자자별 순매수 상위 100 (외국인 | 기관 | 외국인+기관 | 개인 | 외국인+기관+개인)

신호 대상은 시가총액 500억·거래대금 10억 원 이상, ETF·ETN 제외. 금액은 억원(반올림), 빨강 = 유입·상승, 파랑 = 유출·하락.

## 설치

1. 이 저장소에서 `korea-net-buy-top.skill` 파일을 내려받습니다.
2. 파일 확장자를 `.zip`으로 바꾼 뒤, claude.ai의 **Customize → Skills**(claude.ai/customize/skills)에서
   **+ → Create skill → Upload a skill**로 올립니다. (Settings → Capabilities에서 코드 실행이 켜져 있어야 합니다)
3. Settings → Capabilities의 허용 도메인(네트워크 접근)에 아래 두 곳을 추가합니다.
   - `stock.naver.com`
   - `m.stock.naver.com`
4. Claude에게 **"오늘 순매수"**라고 말합니다. 관심 종목이 있으면 "오늘 순매수, 관심 종목은 삼성전자·에코프로"처럼 말하면 됩니다.

로그인이나 브라우저 확장은 필요 없습니다. 전 종목(약 4,300개)을 조회하므로 한 번 실행에 **4~5분** 정도 걸립니다. 정규장(KRX) 기준이며 넥스트레이드(NXT)는 다루지 않습니다.

## 파일 구성

```
korea-net-buy-top/
├── SKILL.md                 Claude가 따르는 작업 설명서
└── scripts/
    ├── fetch_naver.py       네이버 증권에서 데이터 수집 → JSON
    ├── render_html.py       JSON → HTML 페이지 (신호 계산 포함)
    └── archive_check.py     쌓아 둔 일별 데이터로 신호를 긴 기간 점검
```

Claude 없이 직접 실행할 수도 있습니다 (Python 3, 추가 패키지 없음).

```bash
python scripts/fetch_naver.py data.json --watch "삼성전자,에코프로"
python scripts/render_html.py data.json 오늘순매수.html
python scripts/archive_check.py 기록폴더/        # 순매수_YYYYMMDD.json.gz 들을 모아 둔 폴더
```

## 데이터와 계산 방식

| 항목 | 출처 | 정확도 |
|---|---|---|
| 외국인·기관 순매수 금액 (각 상위·하위 100) | 네이버 증권 투자자별 매매동향 | 정확한 값 |
| 그 밖 종목의 외국인·기관, 모든 종목의 개인 | 네이버 종목별 순매수 **수량 × 종가** | 추정 (약 3% 내외 오차) |
| 섹터 추세 (20거래일) | 종목별 일별 수량 × 그날 종가 | 추정 |
| 업종, 종가, 등락률, 거래대금, 시가총액, 지수, 환율 | 네이버 증권 | 정확한 값 |
| 시장 전체 투자자 수급(기관 세부), 외국인 선물 계약 | 네이버 증권 투자자별 매매동향 | 정확한 값 |
| 이벤트일(만기·MSCI) | 달력 규칙으로 계산 | 휴장으로 밀린 날은 반영 못 함 |

- "들어온 돈"의 기본 보기는 **외국인+기관**입니다. 모든 투자자의 순매수를 더하면 종목마다 0에 가깝기 때문입니다(누가 사면 누가 판다).
- ETF는 업종이 아니어서 섹터·종목 흐름에서 빼고 합계만 따로 표시합니다.
- 데이터는 가장 최근 거래일 기준입니다(주말에는 직전 거래일). 장중에 실행하면 "장중 잠정치"로 표시됩니다.

## 기록 쌓기

매일 실행 결과 데이터(`순매수_YYYYMMDD.json.gz`)를 한 폴더에 모아 두면 `archive_check.py`로
"수급 강도 상위 종목이 며칠 뒤 시장보다 나았는가"를 몇 달 단위로 점검할 수 있습니다.
페이지 안의 '신호 점검'은 최근 20일만 보는 맛보기라 표본이 작습니다.

## 주의

- 이 스킬은 공개된 시세 정보를 정리해 보여줄 뿐이며, **투자 조언이 아닙니다.** 페이지에 매수·매도 권유나 전망을 넣지 않습니다.
- 네이버 증권은 게시 정보의 무단 배포를 금지하고 있습니다. 만들어진 페이지는 개인적으로 보거나 아는 사람에게만 공유하고, 공개 웹사이트로 재배포하지 마세요.
- 네이버가 내부 API 주소나 값을 바꾸면 동작하지 않을 수 있습니다. 그런 경우 Claude가 오류 메시지를 보고 고칠 수 있도록 `SKILL.md`에 안내가 들어 있습니다.
