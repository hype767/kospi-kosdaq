# 오늘 순매수 — 코스피·코스닥 투자자별 자금 흐름

Claude에게 **"오늘 순매수"**라고 말하면, 그날 코스피·코스닥에서 외국인·기관·개인의 돈이
**어느 섹터, 어느 종목으로 얼마나 들어오고 빠졌는지** 계산해 한 장짜리 HTML 페이지로 보여주는 Claude 스킬입니다.

단순한 순위 나열이 아니라 "오늘 돈이 어디로 갔나"를 한눈에 보는 것이 목적입니다.

## 페이지에 나오는 것

- **코스피 / 코스닥 탭**과 지수 (종가, 전일 대비, 등락률)
- **요약 카드**: 돈이 가장 많이 들어온 섹터·종목, 가장 많이 빠진 섹터·종목
- **오늘 자금 흐름**: 들어온/빠진 섹터, 들어온/빠진 종목 TOP 15
  - 보기 전환: 외국인+기관 / 외국인 / 기관 / 개인
  - 줄마다 외국인·기관·개인 각각의 몫 표시
- **섹터 추세**: 최근 20거래일 누적으로 돈이 들어온/빠진 섹터, 일별 미니차트, 5일·20일 누적, 연속 유입·유출 일수
- **투자자별 순매수 상위 100** (접혀 있는 참고 표): 종목명, 업종, 순매수 금액, 종가, 등락률, 거래대금

금액 단위는 억원(소수점 반올림), 색은 빨강 = 유입·상승, 파랑 = 유출·하락입니다.

## 설치

1. 이 저장소에서 `korea-net-buy-top.skill` 파일을 내려받습니다.
2. claude.ai 설정의 기능(Capabilities) 메뉴에서 Skills에 이 파일을 업로드합니다.
3. 같은 메뉴의 허용 도메인(네트워크 접근)에 아래 두 곳을 추가합니다.
   - `stock.naver.com`
   - `m.stock.naver.com`
4. Claude에게 **"오늘 순매수"**라고 말합니다.

로그인이나 브라우저 확장은 필요 없습니다. 전 종목(약 4,300개)을 조회하므로 한 번 실행에 **4~5분** 정도 걸립니다.

## 파일 구성

```
korea-net-buy-top/
├── SKILL.md                 Claude가 따르는 작업 설명서
└── scripts/
    ├── fetch_naver.py       네이버 증권에서 데이터 수집 → JSON
    └── render_html.py       JSON → HTML 페이지
```

Claude 없이 직접 실행할 수도 있습니다 (Python 3, 추가 패키지 없음).

```bash
python scripts/fetch_naver.py data.json
python scripts/render_html.py data.json 오늘순매수.html
```

## 데이터와 계산 방식

| 항목 | 출처 | 정확도 |
|---|---|---|
| 외국인·기관 순매수 금액 (각 상위·하위 100) | 네이버 증권 투자자별 매매동향 | 정확한 값 |
| 그 밖 종목의 외국인·기관, 모든 종목의 개인 | 네이버 종목별 순매수 **수량 × 종가** | 추정 (약 3% 내외 오차) |
| 섹터 추세 (20거래일) | 종목별 일별 수량 × 그날 종가 | 추정 |
| 업종, 종가, 등락률, 거래대금, 지수 | 네이버 증권 | 정확한 값 |

- "들어온 돈"의 기본 보기는 **외국인+기관**입니다. 모든 투자자의 순매수를 더하면 종목마다 0에 가깝기 때문입니다(누가 사면 누가 판다).
- ETF는 업종이 아니어서 섹터·종목 흐름에서 빼고 합계만 따로 표시합니다.
- 데이터는 가장 최근 거래일 기준입니다(주말에는 직전 거래일). 장중에 실행하면 "장중 잠정치"로 표시됩니다.

## 주의

- 이 스킬은 공개된 시세 정보를 정리해 보여줄 뿐이며, **투자 조언이 아닙니다.** 페이지에 매수·매도 권유나 전망을 넣지 않습니다.
- 네이버 증권은 게시 정보의 무단 배포를 금지하고 있습니다. 만들어진 페이지는 개인적으로 보거나 아는 사람에게만 공유하고, 공개 웹사이트로 재배포하지 마세요.
- 네이버가 내부 API 주소나 값을 바꾸면 동작하지 않을 수 있습니다. 그런 경우 Claude가 오류 메시지를 보고 고칠 수 있도록 `SKILL.md`에 안내가 들어 있습니다.
