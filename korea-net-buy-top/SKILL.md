# 오늘 순매수 — 투자자별 자금 흐름 (네이버 증권 → HTML)

사용자는 매일 장 마감 후(보통 19시 무렵) "그날 코스피·코스닥에 돈이 어디로 들어왔나"를 본다.
그 뜻은 **투자자별 순매수 금액**(산 돈 − 판 돈)이다. 거래대금 순위가 아니다 — 거래대금은 산 건지
판 건지 알려주지 않기 때문이다.

**목적은 데이터 나열이 아니다.** 페이지를 열자마자 세 가지가 보여야 한다.
1. 오늘 어느 섹터·어느 종목에 얼마의 돈이 들어왔고 빠졌나
2. 그게 누구 돈인가 (외국인 / 기관 / 개인)
3. 추세적으로(최근 20거래일) 돈이 계속 들어오는 섹터와 빠지는 섹터는 어디인가

그래서 화면의 주인공은 자금 흐름과 섹터 추세이고, 투자자별 100위 표는 맨 아래 접힌 참고 자료다.
화면을 고칠 때도 이 우선순위를 지킨다.

두 가지 착시를 피한다.
- 한 투자자만 보면 틀린다. 기관이 SK하이닉스를 6,000억 사도 외국인이 5,700억 팔면 들어온 돈은 300억이다.
  그래서 순매수 목록만이 아니라 전 종목의 투자자별 순매수를 쓴다.
- 모든 투자자를 더하면 종목마다 0에 가깝다 (누가 사면 누가 판다). 그래서 "들어온 돈"의 기본 보기는
  **외국인+기관**이고, 외국인·기관·개인 각각은 보기 전환으로 본다. 세 투자자를 합친 값을 "들어온 돈"이라 부르지 않는다.

투자 조언이 아니라 사실 기록이므로 종목 추천·전망·해석은 붙이지 않는다.

## 1. 실행 (로그인·브라우저 필요 없음)

```bash
python scripts/fetch_naver.py data.json     # 전 종목 약 4,300개 조회, 3~5분
python scripts/render_html.py data.json 오늘순매수_YYYYMMDD.html
```

작업 공간 네트워크에 stock.naver.com, m.stock.naver.com이 허용돼 있어야 한다. 막히면(접속 거부)
사용자에게 claude.ai 설정 → Capabilities에서 두 도메인 허용을 부탁한다. finance.naver.com은 쓰지 않는다.
가져오기는 몇 분 걸리므로 백그라운드로 돌리고, 끝나면 렌더링한다.

`fetch_naver.py`가 쓰는 데이터 (자세한 주소·필드는 파일 맨 위 주석):
- **외국인·기관 순매수/순매도 상위 100** (`trendForeignOrg`): 정확한 금액. 오늘 표와 흐름의 외국인·기관 금액은 이 값을 우선 쓴다.
- **전 종목 목록** (`stocks/marketValue/{KOSPI|KOSDAQ}`): 종가, 등락률, 정규장 거래대금(백만원→억원), ETF 여부.
- **종목별 투자자 순매수 수량 20거래일** (`stock/{code}/trend?pageSize=20`): 외국인·기관·**개인** 수량.
  금액은 수량 × 그날 종가로 추정한다 (삼성전자 외국인으로 비교 시 실제와 약 3% 차이).
  개인은 네이버에 금액 순위가 없어 항상 이 추정치다. 사용자가 이 방식을 골랐다 (KRX는 로그인 필요라 쓰지 않음).
- **업종** (`upjong/{1..399}/info`로 업종 79개를 찾고 `upjong/{code}/stocklist`로 소속 종목): ETF는 "ETF"로 묶는다.

알아둘 것:
- API는 가장 최근 거래일만 준다(주말엔 직전 금요일). 사용자가 다른 날짜를 말했는데 기준일이 다르면 답장 첫 줄에 밝힌다.
- 장중에 돌리면 `estimated`가 참이라 "장중 잠정치"로 표시된다.
- API가 enum 오류를 내면(값이 바뀜) 에러 메시지가 허용값을 알려준다 — 그 값으로 고치고 사용자에게 알린다.
- 사용자는 **순매수 수량 열은 필요 없다**고 했다. 표에 넣지 않는다.

## 2. 화면 구성

`render_html.py`가 만든다. 손으로 HTML을 짜지 않는다 — 매일 같은 모양이어야 비교가 된다.

- **코스피 / 코스닥 탭**: 누르면 그 시장만 보인다 (`#kospi` / `#kosdaq`).
- **요약 카드 4개** (외국인+기관 기준): 돈이 가장 많이 들어온 섹터·종목, 가장 많이 빠진 섹터·종목.
- **오늘 자금 흐름** + 보기 전환 [외국인+기관 | 외국인 | 기관 | 개인]:
  들어온/빠진 섹터, 들어온 종목 TOP 15 / 빠진 종목 TOP 15. 막대 길이로 크기, 줄마다 "외 · 기 · 개" 몫.
- **섹터 추세** + 같은 보기 전환: 최근 20거래일 누적으로 돈이 들어온 섹터 8개 / 빠진 섹터 8개 (20일 누적 순).
  일별 막대 미니차트, 5일·20일 누적, 연속 유입·유출 일수.
- ETF는 섹터·종목 흐름과 추세에서 빼고 합계만 따로 적는다 (업종이 아니라 섹터 비교를 흐린다).
- 맨 아래 접힌 **투자자별 순매수 상위 100**: 외국인/기관(정확)·개인(추정) 탭, 처음 30개 + 더보기.
  열: 종목명, 업종, 순매수 금액(억원), 종가, 등락률, 거래대금(억원). 쌍끌이(외국인·기관 둘 다 상위) ★.
- 색: 빨강 = 유입·상승, 파랑 = 유출·하락. 외국인 파랑 점, 기관 주황 점, 개인 초록 점.
- 페이지 하단에 어떤 금액이 정확값이고 어떤 게 추정인지 적는다.

화면을 바꾼 뒤에는 playwright로 스크린샷을 찍어 핵심 숫자(유입·유출 금액)가 잘리지 않는지 확인한다.

## 3. 전달

- HTML 파일을 사용자에게 보낸다 (Artifact 도구가 있으면 아티팩트로 게시해도 된다).
- 답장은 짧게, 시장별로:
  오늘 돈이 가장 많이 들어온/빠진 섹터와 종목(금액, 누구 돈인지),
  20일 추세로 꾸준히 들어온/빠진 섹터 하나씩.
  외국인과 기관이 반대로 움직여 상쇄된 눈에 띄는 경우가 있으면 한 줄 짚는다. 페이지 내용을 다시 옮기지 않는다.
- 개인 금액과 추세는 추정치라는 걸 한 번 밝힌다.
- 해석·전망·매수 권유는 하지 않는다.
